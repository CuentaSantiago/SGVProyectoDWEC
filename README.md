# SGVProyectoDWEC
## Fecha Creación: 09/10/2026

### Temas:
* UD1 - Arquitecturas y lenguajes de programación

Objetivo de la asignatura:
* Dominar el lenguaje JavaScript: Conocer la sintaxis, la programación estructurada y la Programación Orientada a Objetos (POO) en JavaScript para manipular la lógica de la aplicación en el lado del cliente.
* Manipular el DOM (Document Object Model): Aprender a acceder, modificar, crear y eliminar elementos de una página web de manera dinámica en respuesta a las acciones del usuario.
* Gestionar eventos: Capturar y responder a las interacciones del usuario (clics, envíos de formularios, movimientos del ratón, teclado) mediante controladores de eventos.
* Implementar comunicación asíncrona (AJAX / Fetch API): Enviar y recibir datos del servidor sin necesidad de recargar la página completa, utilizando formatos como JSON o XML.
* Validar y procesar formularios: Garantizar la integridad y el formato de los datos introducidos por los usuarios en el navegador antes de enviarlos al servidor.
* Utilizar librerías y frameworks: Conocer y aplicar bibliotecas o frameworks modernos de JavaScript (como React, Angular o similares) para estructurar aplicaciones web complejas (Single Page Applications o SPA).
* Aplicar criterios de accesibilidad y usabilidad: Diseñar interfaces que cumplan con los estándares web y ofrezcan una experiencia de usuario óptima
